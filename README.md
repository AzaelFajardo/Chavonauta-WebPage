# Chavonauta - Cybercafé & Escaparate Digital

Plataforma web de exhibición (*showcase*) y catálogo interactivo para **Cybercafé Chavonauta**, inspirada en el modelo de diseño modular y autogestión visual de **Tiendanube**.

## Alcance del Proyecto
- **Escaparate Digital y Catálogo (Sin Carrito ni Cotizador)**: Página de muestra diseñada para exhibir el catálogo de productos (accesorios, papelería, snacks) y servicios del cybercafé (impresiones, escaneo, renta de PC/consolas, recargas), promociones vigentes, tarifas, horarios y ubicación.
- **Personalización Visual (Theme Customizer)**: Panel de administración (`/admin`) donde el cliente puede modificar colores, tipografías, logotipo, banners y activar/reordenar las secciones de su página sin depender de desarrolladores.
- **Gestión de Catálogo**: Panel intuitivo para dar de alta, editar, pausar o destacar productos y servicios en tiempo real.
