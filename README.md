# Chavonauta - Cybercafé & Tienda Online

Plataforma web y tienda en línea personalizable para **Cybercafé Chavonauta**, inspirada en el modelo de diseño y gestión modular tipo Tiendanube.

## Características Principales
- **Catálogo de Productos y Servicios**: Venta de accesorios, snacks, servicios de impresión, recargas y renta de equipos/consolas.
- **Personalización Visual (Page Builder / Theme Customizer)**: Panel de administración para modificar banners, colores, secciones de inicio, promociones y catálogo sin tocar código.
- **Carrito de Compras y Pedidos**: Flujo ágil de compra e integración con WhatsApp / pasarelas de pago.
